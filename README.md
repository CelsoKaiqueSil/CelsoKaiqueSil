## `> whoami`

Analista em transição para **Dados e Business Intelligence**, cursando Data Science
na FIAP. Atuo na interseção entre operações NOC, engenharia de dados e automação,
transformando eventos de monitoramento, chamados e planilhas em indicadores,
dashboards e processos rastreáveis.

```text
FOCO        Dados · BI · Automação · Qualidade
STACK       Python · SQL · PostgreSQL · Power BI · Excel
CONTEXTO    NOC Analytics · Service Desk · Monitoramento
OBJETIVO    Analista de Dados Jr. · Analista de BI Jr.
```

## Princípios

- entender o problema antes de escolher a tecnologia;
- automatizar tarefas repetitivas sem perder rastreabilidade;
- tratar ausência de dados como ausência, não como zero;
- validar resultados com testes e regras explícitas;
- publicar apenas dados sintéticos e arquiteturas seguras.
