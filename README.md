## Ferramentas e método

Python e Pandas para tratamento e análise; SQL e PostgreSQL para modelagem;
Power BI, DAX e Excel para indicadores; Git e testes para validar as entregas.

Trabalho com regras de cálculo explícitas, rastreabilidade e exemplos
reproduzíveis. O [estudo da Central de Relatórios](https://github.com/CelsoKaiqueSil/coreops-noc-dashboard/blob/main/docs/REPORT_CENTER_CASE_STUDY.md)
reúne decisões de produto e organização das fontes.
